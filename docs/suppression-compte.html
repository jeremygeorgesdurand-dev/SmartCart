Supprimer son compte SmartCart

Dernière mise à jour : 14 octobre 2026

Depuis l'application (recommandé)

  1. Ouvrez SmartCart et allez dans l'onglet Réglages.
  2. Touchez Compte (en haut de l'écran).
  3. Touchez Supprimer mon compte, puis confirmez avec Supprimer définitivement.

La suppression est immédiate et irréversible.

Ce qui est supprimé

  • Votre compte (connexion Google) et votre profil public (nom, photo).
  • Toutes vos données en ligne : catalogue, rayons, catégories, prix, listes personnelles.
  • Le catalogue et les profils magasin que vous aviez partagés, avec leurs codes.
  • Les listes collaboratives dont vous étiez le dernier membre.

Ce qui est conservé

  • Listes collaboratives avec d'autres membres : vous les quittez ; elles restent pour les autres (la propriété est transmise à un autre membre). Votre nom n'y apparaît plus.
  • Données sur votre téléphone : elles ne sont pas effacées. Pour les supprimer, désinstallez l'application ou videz son stockage dans les paramètres d'Android.
  • Rapports de plantage : informations techniques anonymes, supprimées automatiquement par Google Firebase après une durée limitée.

Sans accès à l'application

Écrivez à VOTRE_EMAIL depuis l'adresse e-mail de votre compte Google, en indiquant « Suppression de compte SmartCart ». Votre demande sera traitée dans un délai raisonnable.
